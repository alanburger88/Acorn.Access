# Acorn OS — Sales Presentation

A self-contained, presentation-ready sales deck for Acorn OS.

## Use it

- **Present:** open `acorn-os-sales-deck.html` in any browser. No install, no build, no network — everything (fonts stack, styles, script, artwork) is inline.
- **Navigate:** `←` / `→` (or Space, click the left/right of a slide, swipe on touch). Number keys jump to a slide; `Home` / `End` go to first / last.
- **Speaker notes:** press `N` (or the **Notes** button) to open the talking-points drawer for the current slide. Notes are written for a live pitch — hooks, objection handling, and the line to land on each slide.
- **Fullscreen:** press `F` (or the **Full** button).
- **Export to PDF / print:** press `P` (or the **PDF** button). Print mode lays each slide above its speaker notes — a ready-to-hand speaker script or a shareable PDF.

## Customize before presenting

Search the file for these placeholders and replace:

- `<client>` / `<date>` on the cover
- `<name>` `<email>` on the closing slide

Both themes (dark for projection, light for print/handout) are supported automatically and follow the viewer's system preference.
