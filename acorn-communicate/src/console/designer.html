Keyboard shortcuts

  

    
↑/↓move block selection

    
Alt+↑/↓move selected block within its level

    
Enteredit first field of selected block

    
Ctrl+Dduplicate selected block

    
Deleteremove selected block (confirms)

    
Escdeselect / close dialogs

    
Enter on paletteinsert that block after the selection

  

  
Every drag action also has a button equivalent (↑ ↓ ⧉ ✕ on each block, “+ Add block” inside sections).
